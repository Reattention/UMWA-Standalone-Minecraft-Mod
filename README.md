# UMWA - Ultimate Minecraft World Analyser

A comprehensive Minecraft mod that provides advanced mining analysis, world exploration tools, and AI-powered mining optimization features.

## Features

### 🏔️ Core Mining Analysis
- **3D Cave Visualization** - Real-time 3D rendering of explored cave systems
- **Ore Distribution Analysis** - Shows where valuable ores are located
- **Mining Efficiency Tracking** - Monitors blocks mined vs. ores found
- **Unexplored Area Detection** - Highlights areas you haven't explored yet
- **Cave System Mapping** - Maps connected cave networks and tunnels
- **Depth Analysis** - Shows mining activity by Y-level/depth

### 📊 Resource Analytics
- **Ore Prediction** - AI-powered predictions of where ores might be
- **Mining Progress Tracking** - Percentage of area explored
- **Resource Yield Reports** - Diamonds/Iron/Gold per chunk statistics
- **Hotspot Detection** - Identifies high-value mining areas
- **Biome Mining Analysis** - Different strategies per biome
- **Vein Tracking** - Follows ore veins to completion

### 🌍 World Integration
- **Real-time Block Updates** - Tracks every block you mine/place
- **Chunk Loading Detection** - Knows which areas are loaded
- **Player Position Tracking** - Your exact coordinates and movement
- **Multi-dimensional Support** - Works in Overworld, Nether, End
- **Structure Detection** - Finds dungeons, strongholds, villages
- **Biome Recognition** - Adapts analysis to different biomes

### 🎯 Smart Mining Features
- **Optimal Mining Paths** - Suggests most efficient mining routes
- **Branch Mining Optimizer** - Perfect spacing for maximum coverage
- **Risk Assessment** - Warns about lava/water/mob spawners nearby
- **Tool Recommendations** - Best pickaxe/enchantments for area
- **Time Estimation** - How long to mine a specific area
- **Resource Prioritization** - Focus on most valuable targets first

### 🖥️ User Interface
- **Minimap Display** - Shows cave systems and ores on minimap
- **HUD Integration** - Mining stats overlay on screen
- **Waypoint System** - Mark important locations and ores
- **Progress Bars** - Visual progress of mining objectives
- **Alert System** - Notifications for valuable ore discoveries
- **Quick Stats** - Instant access to mining metrics

## Installation

1. Install Fabric Loader for Minecraft 1.20.4+
2. Install Fabric API
3. Download the UMWA mod file
4. Place in your `mods` folder
5. Launch Minecraft

## Controls

- **H** - Toggle Mining HUD
- **M** - Toggle Minimap
- **U** - Open Mining Menu

## Technical Requirements

- **Minecraft**: 1.20.4+
- **Fabric Loader**: 0.15.0+
- **Fabric API**: Latest version
- **Java**: 17+

## Building from Source

```bash
git clone https://github.com/Reattention/UMWA-Standalone-Minecraft-Mod.git
cd UMWA-Standalone-Minecraft-Mod
./gradlew build
```
